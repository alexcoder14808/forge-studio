# Forge Studio

A dependency-free visual website/app builder prototype designed to run as a static site.

## Features

- Visual page builder
- Multi-page projects
- Drag/drop elements
- Website sections
- App-style UI blocks
- Form components
- Inspector
- Responsive desktop/tablet/mobile canvas
- Undo/redo
- Preview
- Project JSON export
- Static HTML export
- Local autosave
- GitHub Pages compatible

## Run locally

Open `index.html` in a modern browser, or use any static server.

## GitHub Pages

Push the repository to GitHub and enable Pages using GitHub Actions. The included workflow deploys the repository on pushes to `main`.

## Important architecture note

This is a static builder prototype. A production SaaS needs a backend for authentication, cloud projects, databases, file storage, publishing, custom domains, collaboration, server-side forms, payments, integrations, secrets, and AI services.
